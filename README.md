# Metapsyche

A modern React application built with Vite and AWS Amplify Gen 2, featuring authentication, GraphQL API, and real-time database capabilities.

## 🚀 Quick Start

**New to this project?** See [QUICKSTART.md](QUICKSTART.md) for a 5-minute setup guide.

## Overview

This project uses AWS Amplify Gen 2 to provide a fully-integrated backend with:
- **Authentication**: Secure user authentication with Amazon Cognito
- **API**: GraphQL endpoint powered by AWS AppSync
- **Database**: Real-time data with Amazon DynamoDB

## Tech Stack

- React 18 with TypeScript
- Vite 6 for fast development and optimized builds
- AWS Amplify Gen 2 (backend and UI)
- AWS CDK for infrastructure as code

## Getting Started

### Prerequisites

- Node.js 18+ and npm
- AWS Account
- Git

### Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the Amplify sandbox:
   ```bash
   npx ampx sandbox
   ```
   This creates temporary backend resources. Keep this running.

3. Start the development server (in a new terminal):
   ```bash
   npm run dev
   ```

4. Open `http://localhost:5173`

## Deploying to AWS Amplify

### Quick Deploy

1. Push your code to a Git repository
2. Go to [AWS Amplify Console](https://console.aws.amazon.com/amplify/)
3. Click "New app" → "Host web app"
4. Connect your repository
5. Click "Save and deploy"

Amplify automatically uses the `amplify.yml` configuration to:
- Deploy the backend (Cognito, AppSync, DynamoDB)
- Build and deploy the frontend
- Set up HTTPS and CDN

For detailed deployment instructions, see [DEPLOYMENT.md](DEPLOYMENT.md).

## Environment Configuration

The application uses `amplify_outputs.json` (auto-generated by Amplify) for configuration. This file contains:
- Cognito User Pool configuration
- AppSync API endpoint
- API keys and authorization modes
- AWS region settings

**Note**: This file is gitignored and generated during sandbox/deployment. See [DEVELOPMENT.md](DEVELOPMENT.md) for details.
